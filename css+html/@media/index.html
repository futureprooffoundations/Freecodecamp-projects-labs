html h

h elements can vary in size starting h1 the largest to h6 the smallest.

You should start with

  1. h1
    2. for titles and then
  2. h2
    3. for headings and
  3. h3
    4. for sub-headings and so on.
That will help in SEO which will help in traffic. for e.g:

<h1>title</h1>
html p

This element is used for:

  • paragraphs
  • text

you can style it and decorate it using CSS for e.g:

<p>text here</p>
html a

this is used for links or anchors

it contains href attribute that withold the link for e.g:

<a href="example.com">click here</a>
html img

This element is used for Images

It contain src attribute that link to the image for e.g:

<img src="example.com">
html code

This is used to represent code

Its very useful in technical documents. for e.g:

<code>code goes here</code>
